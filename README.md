# Zeros-cleared leaderboard — retired classroom demonstration

A classroom demonstration that displays a leaderboard for clearing missing assignments. It is retained as an archived reference and is no longer an active project.

## Contents

- `index.html` and `style.css` — the static HTML version.
- `zeros-react-app/` — an experimental React/Vite version.

The original source files and commit history are preserved. The existing GitHub Pages configuration and address have been retained.
